JSONDesk

Pretty-print, minify, and validate JSON. Optional path/key search. Everything stays in your browser.

Tree view


    


    

      How it works
      

        Parsing uses the browser’s native JSON.parse. Pretty uses 2-space indent;
        Minify removes whitespace. Path search walks objects/arrays and matches full paths
        (dot + [index]) or key names. Nothing is sent to a server.
