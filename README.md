# JSONDesk

**In-browser JSON pretty-print, minify, and validate.** Paste JSON, format it, catch errors with line/position hints, and optionally search by path or key. Optional tree view.

**Live:** https://shaikbasha1437.github.io/jsondesk/

## Privacy

All parsing and formatting run **only in your browser**. Your JSON never leaves this tab — no uploads, no accounts, no analytics.

## Features

- Pretty-print (2-space indent)
- Minify
- Validate with clear error messages (line / column / position when available)
- Copy result
- Sample JSON loader
- Path / key search (matches full paths or key names)
- Optional tree view
- Works offline after first visit (PWA)

## How to use

1. Open the live page (or open `index.html` locally).
2. Paste JSON into the editor (or click **Sample**).
3. Use **Pretty**, **Minify**, or **Validate**.
4. Optionally search with a path or key (e.g. `user.email` or `email`), and toggle **Show tree**.
